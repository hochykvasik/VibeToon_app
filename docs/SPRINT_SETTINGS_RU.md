# Спринты 6.8 / 6.9: что работает, что «В разработке»

Документ ведётся вместе с `CHANGELOG_RU.md`. Пункты настроек, не подключённые к логике, в окне «Настройки» подписаны
«В разработке» и выключены (переключатель серый). Подключённые сохраняются в `SharedPreferences` (`vt_app`) и действуют сразу.

## Спринт 6.8

| Функция | Статус | Где | Как устроено |
|---|---|---|---|
| Поворот холста двумя пальцами | ✅ | жест на холсте без выделения; «Настройки → Жесты → Поворот холста двумя пальцами» (вкл. по умолчанию) | Только вид: `Camera.rotation` → `RenderNative.setCamera` → `vt::makeView`. Порог 7° (щипок без случайного поворота), притяжение к 0/90/180/270° (±4°). Экспорт/снимки всегда без поворота (`beginExport` сбрасывает вид). |
| Быстрый сброс в 0° | ✅ | плашка «37°» сверху холста (тап по числу), «Действия → Поворот вида: 0°» | `resetViewRotation()`: точка холста в центре экрана и масштаб сохраняются. |
| Поворот на ±90° | ✅ | ⟲ / ⟳ на плашке, «Действия» | `rotateViewBy(±90)` |
| Flip Canvas (отражение вида) | ✅ | «Настройки → Общие → Отразить холст по горизонтали/вертикали», «Действия → Отразить холст по горизонтали» | `Camera.flipX/flipY`; только вид, рисунок и экспорт не меняются. Жест поворота слоя при отражённом виде инвертируется (`Camera.handedness`). |
| Правка опорной точки слоя (Layer Pivot Editing) | ✅ | одиночное выделение слоя/группы → перекрестие на холсте, тащится пальцем; «Слои → свойства → В центр» | `LayerProps.pivotX/pivotY` (сдвиг от центра рамки, сохраняется в проекте, ключи `px/py`). При переносе сдвиг base/override/всех ключей компенсируется (`PivotMath.compensate`): на ключевых кадрах слой не прыгает. Притяжение к углам/серединам/центру рамки (14 px). Undo одним шагом. |
| Временные опорные точки (Temporary Pivots) | ✅ (выкл. по умолчанию) | «Настройки → Инструменты» | Поворот/масштаб слоя двумя пальцами вокруг точки между пальцами (`PivotMath.aroundPoint`). |
| Auto Pixel Edit Mode | ✅ (вкл. по умолчанию) | выбор Кисти/Ластика | Если выделенный слой не годится для рисования (группа, текст, символ, камера, ничего), выбирается верхний видимый незапертый слой-картинка; нет такого - создаётся «Рисунок N». Векторный слой не трогается (кисть рисует контуры). С «Vector Workflow» кисть выбирает/создаёт векторный слой. |
| Only Erase/Smudge Selected Path Layers | ✅ (выкл. по умолчанию) | Ластик на векторном слое, «Смазка» на векторном слое | Новый векторный ластик режет пути/ломаные/прямые, замкнутые фигуры удаляет целиком (залитые - и касанием внутри). Палец гнёт пути. Без флага - все видимые незапертые векторные слои, с флагом - только выделенные. Один шаг Undo на мазок. |
