## Описание

+ Add -> Text creates a text layer (input dialog with the keyboard); the text is rendered to a Bitmap
with TextPaint/StaticLayout and uploaded through uploadBitmap, so it works with transforms and keyframes;
Text inspector tab (text, font, size, color), system font families plus imported TTF/OTF stored in the
app fonts folder, debounced re-render keeping the layer center, text layers are hit-tested by their
whole box, text saved in project.json and restored on open.
