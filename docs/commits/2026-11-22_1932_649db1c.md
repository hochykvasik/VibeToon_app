## Описание

- символы: снимок в размере холста (без потолка 1024), кэш картинок, по одному снимку (Mutex), при сбое прежняя текстура и повторы с паузой; участники символов не перезаливаются главной сценой; миниатюры маркеров 320 px асинхронно
- GL: GlStateGuard для внеэкранных проходов, подложка режимов наложения пересоздаётся по размеру цели, отдельные цели снимка/экспорта, снимок = одна отрисовка после загрузки текстур
- бюджет текстур: замена учитывается, при нехватке уменьшение вдвое вместо пропадания слоя; очередь загрузок заменяет кадр того же слоя
- жизненный цикл: onPause/onResume в GLSurfaceView, тяжёлые задачи не ставятся на паузе, экспорт останавливается, после потери контекста текстуры заливаются заново, abandon без вызовов GL
- Pencil: зерно холста (CANVAS) + CAP_OPACITY
- экспорт: recordable EGL-конфиг, стороны кратны 16 и проверены кодеком, запасной путь YUV420 (Image API, шаги строк), «Совместимый экспорт видео» в настройках
- тесты: SymbolQualityTest, ExportYuvTest, PencilGrainTest, ExportMathTest, GrainPresetTest, TexMathTest.cpp
