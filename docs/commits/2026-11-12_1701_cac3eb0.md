## Описание

'+' Add menu (PSD, image, video, audio) with the system file picker; files are copied into the
project folder, images/video frames are decoded (EXIF rotation, downscaled to 2048 px) and uploaded
to the renderer as textures through a new JNI uploadBitmap; media layers sit in canvas space above
the PSD and use the same tree, selection, inspector and keyframes; audio becomes a non-visual
timeline row with its length; media is restored when a project is reopened.
