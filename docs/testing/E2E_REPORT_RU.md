# E2E-отчёт: сквозная проверка VibeToon (APK 20261119-1418)

Среда: эмулятор sdk_gphone64_x86_64, экран **телефона** 2400x1080 в ландшафте (не планшет), чистая установка, без пересборки, ничего не чинилось. Файлы экспорта разбирались с устройства (Pillow, zipfile).

**Честно об объёме.** Пройден первый содержательный срез по всем четырём блокам. Полный перечень из ~100 сценариев задания **не исчерпан**: см. раздел «Не проверено». Всё, что в разделах 1-4, видел на экране или в файле.

## 1. Работает (проверено)
- **Онбординг и внешний вид:** язык RU/EN, тема, 8 акцентов; всё применяется сразу, без перезапуска; тёмная тема и зелёный акцент корректны.
- **Создание проекта:** пропорции, разрешение, 24/30/60 fps, фон; карточка показывает «16:9 · 30 fps · 4.0 с · 197 КБ», миниатюра отражает содержимое (автосохранение подтверждено: после выхода кнопкой «Назад» и повторного открытия всё на месте).
- **Меню проекта (⋮):** «Переименовать, Дублировать, В папку, Резервная копия .tsproj, Удалить». **Дублировать** создаёт «… (копия)» с тем же содержимым. **Резервная копия .tsproj**: валидный ZIP (project.json, assets/…png, thumbnail.png, tsproj.json), системный диалог сохранения, тост «Резервная копия сохранена».
- **Слои:** меню «+» содержит Пиксельный, Анимационный (покадровый), Векторный, Группа, Фон, Аудио, Видео, Изображение, Текст, Камера (Pan & Zoom), Transform Layer (null); список прокручивается. Пиксельный, текстовый и векторный слои создаются.
- **Кисть:** штрих рисуется, рамка слоя облегает нарисованное (баг из 6.3 исправлен). Undo/Redo доступны.
- **Текст:** добавление, вкладки «Трансформация / Текст / Клип», выравнивание Слева/По центру/Справа, **межстрочный (160%) и межбуквенный (30%) интервалы работают визуально**, заливка/градиент, обводка, 5 текстовых эффектов (Печать по буквам, Счётчик/таймкод, Тряска, Текст по контуру, Рандомизатор) и «Толщина шрифта» присутствуют.
- **Заливка:** панель (Порог 32, Расшир. 1, Зазор 2); на выбранном слое заливает область, Undo откатывает, Redo активируется; без выбранного слоя показывает подсказку «Инструмент работает на слое-картинке».
- **Выделение:** панель Прямоугольник / Овал / Лассо / Палочка.
- **Вектор:** слой создаётся; список фигур (Круг, Квадрат, Треугольник, Звезда, Стрелка, Сердце, Диалог) и режимы Путь/Линия/Прямоугольник; звезда нарисована.
- **Таймлайн:** воспроизведение идёт (00:02:01 на 4 с), линейка автопрокручивается за плейхедом, Undo/Redo на время игры блокируются; кнопка магнита даёт подсказку «Магнит включён».
- **Обучение:** карточка статьи открывает экран «Как добавить и анимировать текст» с иллюстрацией и кнопкой «Пройти в редакторе».
- **Экспорт (файлы проверены):**
  - **MP4** 720p/30, 120 кадров, 144 КБ, «без звука» указано честно.
  - **GIF** 1280x720, 96 кадров, 1892 КБ, бесконечный цикл; кадр 40 мс (24 fps округлено до центисекунд, ~4% быстрее).
  - **PSD** валиден (сигнатура 8BPS, 1920x1080 RGBA, открывается Pillow), но **11.6 МБ** на 3 слоя.
- **Устойчивость:** падений нет, в crash-буфере пусто.

## 3. Недоделанное / UI / перевод
- **Перевод настроек:** при русском языке **вся** вкладочная часть «Настройки» остаётся английской: вкладки General, Tools, Import, Display, Gestures, Keyboard и подписи внутри (Left Handed, Show Grid, Show Symbol Context, Symbol Context Opacity …). Переведена только вкладка «Внешний вид».
- «Symbol Context Opacity» оформлен переключателем (вместо слайдера) и, по-видимому, заглушка.
- Заголовок «Ваши проекты» дважды при пустом списке; терминология «Пиксельный» (меню) и «Картинка» (подпись).
- На экране телефона в ландшафте: таймлайн занимает ~20% высоты (одна-две дорожки), панель параметров инструмента перекрывает верх холста («Размер» обрезан), панель «Свойства» открывается на вкладке с обрезанным низом (нужен скролл), лист «Новый проект» требует прокрутки до «Создать», кнопка «Назад» в редакторе при закрытой клавиатуре сразу выходит в список без подтверждения.
- Экспорт «Только аудио (WAV)» в списке форматов отсутствует при проекте без звука (вероятно, скрывается; не проверено).
- В MP4 нет звука (известное ограничение).

## 4. Производительность и стабильность
- Падений и ANR нет; рисование, заливка, Undo/Redo, воспроизведение, экспорт MP4 (120 кадров 720p ~ несколько секунд) и PSD прошли без зависаний.
- **GIF 1280x720 на эмуляторе: ~5 кадров/с рендера** (96 кадров заметно дольше 20 с, прогресс «Кадр 54 из 96» к 12-й секунде). Это эмулятор на CPU, на реальном планшете нужно перемерить.

## Порция 3 (дополнение)
- **B12 разобран: задумано, но плохо объяснено.** По коду (`MainViewModel.storeEdit`): если у слоя нет ключей, правка жестом пишется в статичную «ручную трансформацию» и действует на всех кадрах. Если ключи есть и на кадре ключа нет, правка временная и сохраняется только кнопкой «Добавить ключ»; если ключ на кадре есть, правится он. Для пользователя это неочевидно, рекомендация: подсказка при первой правке «слой без анимации, правка для всех кадров, нажмите ключ для анимации». Баг-статус: **UX, не дефект логики**. Визуально на эмуляторе подтверждено: позиция звезды на кадрах 0 и 19 одинакова после сдвига без ключей.
- **PNG-последовательность (ZIP): работает.** 4259 КБ, ZIP валиден (`testzip` без ошибок), **96 файлов** (4 с × 24 fps), в диалоге честно написано про замену MOV с альфой. Размер и прозрачность не разбирались (мой скрипт упал на выводе кириллицы).
- **Новая находка B14:** при высокой панели таймлайна холст-превью сжимается до ~250×150 px и подсказки («Магнит включён…») полностью его перекрывают; редактировать на таком виде практически нельзя (ограничение телефонного экрана).
- **Не пройдено в этой порции, несмотря на запрос:** Hold/Step, Stretch, Reverse ключей (на сжатом таймлайне ключи не видно, нужен планшетный размер или портрет); эффекты (FX-цепочка); аудио (на эмуляторе нет аудиофайлов, только тесты `VolumeTest`/`WavTest` из спринта 6.4, они зелёные); кости и сетки; Resize/Crop; поиск проектов (имена кириллические, а `adb input` не вводит кириллицу; проверить можно только после переименования проекта на латиницу).
