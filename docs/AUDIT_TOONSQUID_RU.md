# Аудит VibeToon против чек-листа ToonSquid (19.11.2026)

Метод: сверка по коду (инструменты, модели проекта, C++ рендерер, настройки) и по тому, что реально проверялось на эмуляторе в спринтах 3-5.2. Оценивалась суть функции, а не название. Пометка **(п)** - в коде есть, но на экране в этом аудите заново не проверялось; **(з)** - кнопка есть, но это заглушка («в разработке»).

## 1. Уникальные фичи VibeToon (нет в списке ToonSquid)
| Фича | Описание |
|---|---|
| Липсинг-панель маркеров | Плавающая панель-сетка с миниатюрами форм рта, перетаскивается, прячется к краю |
| «Слои как кадры» | Из выделенных слоёв делается символ, где каждый слой - кадр с авто-маркером по имени слоя |
| Интерактивный урок + Coach | Учебный проект и пульсирующие подсказки поверх реального интерфейса, «Пропустить» |
| Туториалы в приложении | 9 статей с плашками кнопок и схемами |
| Эффекты FX-цепочки: Tiles, Mirror, Wave, Vignette, RGB Split, Shake, Beat/Pulse, Spin, Displacement, Invert, Zoom/Motion Blur | Богаче списка ToonSquid |
| Текстовые эффекты | Печать по буквам, счётчик/таймкод, тряска, текст по контуру, рандомизатор символов, градиент, обводка |
| 8 акцентных цветов + светлая/тёмная тема | Динамические схемы Material 3, переключение на лету |
| Русский/English на лету | Язык без перезапуска, онбординг первого запуска |
| Автопродление проекта под звук | Проект сам растёт до конца аудио |
| Кэш волны `.wave` | Мгновенное открытие аудио-дорожки |
| Лесенка | Клипы выбранных слоёв встык одним нажатием |
| Магнит плейхеда | Прилипание к ключам, маркерам, краям клипов |
| Автопрокрутка таймлайна у края | При перетаскивании плейхеда |
| Цикл в проекте | Loop хранится в файле проекта |
| Векторный слой на примитивах | Путь/линия/прямоугольник/эллипс/фигуры как список примитивов, Undo/Redo |
| Библиотека фигур | Круг, квадрат, треугольник, звезда, стрелка, сердце, облако-диалог |
| Асинхронный Undo штриха (PBO) | Конец штриха не замораживает рендер |

## 2. Бэклог: что из списка ToonSquid ещё нужно сделать
**Проекты и файлы**
- Несколько сцен в одном проекте **(з: кнопка «Сцена 1»)**
- Crop и Resize холста после создания **(з: «Project Info»)**
- Сетка/список, поиск, сортировка проектов (только сетка)
- Импорт/экспорт проектов (.tsproj и свой формат), кистей, палитр **(з)**
- Очистка кэша, удаление осиротевших ассетов
- Новая папка **(з)**

**Слои**
- Transform Layer (null-объект), Path Layer (контур как траектория), Bone Layer как отдельный слой
- Слой-маска и маска из любого слоя, инверсия, скрытие маски (есть только обтравочная маска «Маска вкл/выкл»)
- Режимы наложения: есть 5 (Normal, Multiply, Screen, Overlay, Soft Light); нужны Add, Darken, Lighten, Color Dodge, Color Burn и др.
- Анимационный слой как контейнер экспозиций: сейчас это картинка с ячейками, без операций «увеличить/уменьшить экспозицию», Merge
- Векторный слой: узлы, перо с безье и подконтурами, выделение/правка отдельного примитива, ластик, SVG, морфинг форм

**Графика**
- Инструменты на панели слева — заглушки: **Выделение, Заливка, Пипетка (инструмент), Путь, Смазка**
- Flood Fill (порог, Expand, Gap Closing), Smart Recolor, Fill Eraser
- Лассо, прямоугольное/овальное выделение, волшебная палочка
- Свободная трансформация: Skew, Distort (есть Perspective по 4 углам)
- Временный пивот, правка пивота слоя
- Направляющие: сетки, изометрия, перспектива, симметрия, линейка
- Кисти: Scatter, Tilt, Speed-отклик, стабилизация линии; свои кисти и импорт/экспорт
- Shape Assist (стилус задерживается - фигура)
- Цвет: гармонии, сохраняемые палитры (в ColorPicker есть круг и история; гармоний нет) **(п)**

**Анимация**
- Hold/Step для обычных ключей слоя (есть только Linear, Ease In, Ease Out, Ease In-Out и кривая; Hold есть у ключей времени символа)
- Stretch Keyframes, реверс ключей (есть копирование/вставка)
- Motion Path: траектория по контуру, Orient Along Path
- Параллакс камеры и Z-глубина слоёв
- Калька: цвета и прозрачность отдельно для прошлых/будущих, Out of Pegs (цвета фиксированы: красный и зелёный, общая прозрачность)
- Символы: режимы Play Once и Single Frame по номеру кадра символа (есть Loop и ключи времени Hold), In-Context Editing с полупрозрачной сценой
- Цветовая маркировка и скрытие/блокировка отдельных костей, радиус влияния привязки (есть вес Strength)
- Анимация цвета и параметров эффектов по ключам **(п)**

**Звук и текст**
- Громкость (Volume) с ключами, обрезка аудиоклипа (есть клип с краями на таймлайне)
- Выравнивание, межстрочный/межбуквенный интервал, RTL

**Интерфейс и экспорт**
- Flip Canvas, режим левши, настраиваемые жесты, горячие клавиши (в настройках пункты-заглушки; горячие клавиши по умолчанию есть)
- Экспорт: MOV с альфой, PNG Sequence в ZIP, PSD с иерархией, проект (.tsproj), только аудио **(есть кнопки, все неготовы)**
- Заглушки: «Добавить слой» уже закрыто; остались «Библиотека», «Справка», настройки инструмента по повторному нажатию
