# Контрольный аудит VibeToon против чек-листа ToonSquid (после спринта 53)

Предыдущая версия аудита (после спринта 40) осталась в истории git.

**Как проверяли.** Только по коду, не по названиям: модели проекта, `MainViewModel`, C++/GLES-рендерер, экспорт, настройки, разметка интерфейса. Учитывалось, доступна ли функция из UI, а не только есть ли она в коде. На устройстве ничего не проверялось: перо, 120 Гц и GPU требуют проверки на планшете.

**Объём:** ~55,5 тыс. строк Kotlin, ~20,7 тыс. строк C++/GLSL, 1256 JVM-тестов в 221 файле, нативные C++-тесты политик рендера, RU/EN 2314 строк.

Обозначения: ✅ готово · ◐ частично или альтернативной реализацией · ✖ нет.

## Исправления к прошлому аудиту (там было завышено)

- **Менеджер проектов: режима «Список» нет.** Только адаптивная сетка карточек (`LazyVerticalGrid`). «Список» есть у слоёв, не у проектов.
- **Сцены: своего размера холста нет.** Сцена - отрезок общего таймлайна со своими слоями, фоном и переходом. Независимого таймлайна у сцены нет.
- **Mesh: ручного добавления, перемещения и удаления вершин в UI нет.** Инструменты `MeshTool.ADD / MOVE / DELETE` есть во ViewModel, но после перехода на пины кнопок на панели не осталось: только «+Пин», «Пин», «Разрез», «Кисть».
- **Закрыто с прошлого аудита:**
  - длительность до 72 000 кадров (было 5000);
  - экспозиция рисунка «Длина − / +» с удержанием;
  - все переключатели настроек рабочие (заглушек «В разработке» нет).

## 1. Уникальные фичи VibeToon (нет в ToonSquid)

| Фича | Суть |
|---|---|
| Липсинг-панель маркеров | Плавающая сетка миниатюр форм рта; тап ставит ключ времени Hold на плейхеде |
| «Слои как кадры» | Выделенные слои → символ, каждый слой - кадр с маркером по имени |
| Переходы между формами символа | Растворение между разными формами вместо резкой смены (кроме Hold) |
| Импорт чужих форматов | Procreate, Krita `.kra` (сведённое), OpenRaster `.ora`, Lottie `.json/.lottie` → вектор, ZIP с кадрами, GIF, секвенции, PSD с замками и редактируемым текстом |
| Видео как символ, плёнка клипа | Кадры видео на таймлайне, скорость, реверс, стоп-кадр, цикл, звук видео в экспорте |
| Переходы между сценами | Растворение, сдвиг, через чёрный/белый; Play и экспорт по сцене |
| Расширенный FX-стек | 25 эффектов + Turbulent-деформер; сверх ToonSquid: Tiles, Mirror, Wave, Vignette, RGB Split, Shake, Pulse, Spin, Swing, Stretch Axis, Zoom/Motion Blur, Invert, карта смещения, Line Boil (3 шума); эффекты группы целиком |
| Текстовые эффекты | Печать по буквам, счётчик/таймкод, тряска, дуга, рандомизатор, градиент, обводка, толщина; полный Unicode Bidi |
| Булевы операции вектора | Объединение, вычитание, пересечение, XOR неразрушающе; «Разобрать» |
| Векторные кисти | «По нажиму», «Тушь», «Каллиграфия»: толщина по узлам, штрих остаётся вектором |
| 4 режима наклона пера, редактор кривой нажима | «Толщина», «Штриховка», «Плоское перо»; пресеты кривой и тестовая площадка |
| Деформеры | Puppet-пины (ARAP), плотный Warp до 32×32, Perspective, деформер-путь (как в Live2D), Stretch; для слоя и группы, с ключами |
| Отделение части деформированного слоя | Вырезать/копировать в новый слой вместе с деформерами и ключами |
| Дубль «С анимацией / Без анимации» | Без анимации - чистый слой в позе текущего кадра |
| Покадровка: плашка «Новый кадр: N» | Тянется пальцем 1–48, удержание «Длина − / +» с ускорением, одна отмена на серию |
| Слои-рисунки лесенкой + калька по ним | «+ Кадр» создаёт следующий слой-рисунок; калька видит соседние слои группы |
| Таймлайн-инструменты | Лесенка (встык/каскад), магнит плейхеда и краёв плашек, меню «Плашка: флажки и плейхед», «Точное время» в секундах или кадрах, общая кривая на разных слоях |
| Рисование прямо на PNG и PSD, «Слить вниз» с режимом наложения | Без создания пустого слоя |
| Автопродление проекта под звук и видео, кэш волны `.wave` | Проект растёт до конца медиа, волна открывается мгновенно |
| Библиотека проектов | Папки, ручная сортировка, мгновенный перенос в папку (правка только заголовка `project.json`), кэш превью и размеров |
| Резервная копия настроек | JSON со всеми настройками, своими кистями, палитрами, последними цветами |
| Экспорт «Только аудио (WAV)», свой MOV-муксер | MOV с альфой без системных кодеков (PNG + PCM) |
| Проверка кодеков перед экспортом | HEVC/H.264, fps и битрейт сверяются с устройством, понятные пояснения |
| Обучение | 14 уроков, тур и подсказки Coach поверх настоящих кнопок; урок покадровой анимации |
| RU/EN на лету, темы и 8 акцентов, Performance HUD | Без перезапуска; метрики кадра, адаптивный бюджет GPU |

## Риски на тесте

- Растр ≤ 2048 px на 4K-холстах; аудио ≤ 5 минут на дорожку; Crop/Resize без Undo.
- `MainViewModel` ~14,3 тыс. строк: на больших проектах возможны лишние рекомпозиции.
- Перо и 120 Гц не проверены на устройстве.

**Перед переустановкой** сохраните вне приложения все проекты (Экспорт → «Проект (.tsproj)» или менеджер проектов) и «Резервную копию вручную» настроек.
