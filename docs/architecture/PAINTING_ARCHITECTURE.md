# Рисование: Кисть и Ластик (этап 1)

## Что где лежит
| Часть | Файл |
|---|---|
| Математика штампов: шаг, сплайн, логарифмический слайдер | `domain/paint/BrushMath.kt` (`DabStroker`, `BrushMath`) |
| Запись Undo (до / после, Deflater, лимит памяти) | `domain/paint/PaintOp.kt` |
| GL: Stroke FBO, штампы, запекание, dirty rect | `cpp/render/Paint.cpp`, объявления в `Renderer.h` |
| JNI | `RenderBridge.cpp`, `RenderNative.kt`, `VtGLSurfaceView.kt` |
| Состояние, жесты, Undo, сохранение | `MainViewModel.kt` (раздел «Рисование») |
| Ввод пера и пальца | `MainScreen.kt` (`EditorCanvas`) |
| Панель настроек | `EditorShell.kt` (`PaintToolRow`) |

## Конвейер штриха
1. `ACTION_DOWN`: `paintBegin`. Слой копируется в `backup` (glBlitFramebuffer), `Stroke FBO` очищается.
2. Движение: Kotlin считает штампы (`DabStroker`) и шлёт пакеты `paintDabs` (x, y, радиус, непрозрачность).
   - Каждый пакет рисуется в `Stroke FBO` instanced quads (`glDrawArraysInstanced`).
   - Превью: в прямоугольнике пакета слой = `backup` + `Stroke FBO`, запечённый по правилам режима. Потом `glGenerateMipmap`.
3. `ACTION_UP`: `paintEnd(commit)`. Читаются пиксели ДО (из `backup`) и ПОСЛЕ (из слоя) для охвата штриха (dirty rect), всё уходит в Kotlin. Там `Deflater.BEST_SPEED` в фоне.
4. Слой помечается на сохранение; запись добавляется в общий Undo.

## Режимы Stroke FBO
| Режим | Накопление штампов | Запекание в слой |
|---|---|---|
| CAP_OPACITY (маркер) | `GL_MAX` по 4 каналам | `ONE, ONE_MINUS_SRC_ALPHA`, непрозрачность штриха |
| ACCUMULATE (аэрограф) | premultiplied `ONE, ONE_MINUS_SRC_ALPHA`, работает Flow | то же |
| ERASE | `GL_MAX` маски | Destination-Out `ZERO, ONE_MINUS_SRC_ALPHA` |

Flow относится к каждому штампу, Opacity - только к запеканию штриха.

## Штампы
- Круг: мягкий край `smoothstep` от `radius*hardness` до `radius`; при жёсткости 1 край сглажен на 1 px. Квадрат: бинарная отсечка `step()`.
- Путь: Centripetal Catmull-Rom между точками, исторические точки `MotionEvent` берутся все. Шаг считается накопителем остатка расстояния, поэтому штампы идут равномерно и не слипаются на стыках событий.
- Умный шаг: `EffectiveSpacing = clamp(base * (1 + R/300), base, 0.4)`.
- Размер: диаметр в пикселях слоя (1..1500), регулятор логарифмический (`Size = 1 * 1500^t`). Давление пера меняет размер (минимум `minSizePercent`).

## Undo / Redo
- Запись штриха лежит в общем стеке отмены (`Snapshot.paintOp`): отмена возвращает пиксели «до», повтор - «после».
- Восстановление прямоугольника - `glTexSubImage2D` (прямая перезапись, без смешивания), потом mip-уровни и карта прозрачности для hit-test.
- Лимит 160 МБ на стеки Undo/Redo: старые записи вытесняются вместе с записями под ними (`PaintBudget`).

## Сохранение
- Изменённые слои пишутся в PNG при каждом автосохранении и при выходе из проекта (`flushPaintSaves`): у картинки это сам файл, у слоя PSD - `assets/liq_<id>.png` (как у Liquify).
- «Новый слой»: пустая прозрачная картинка размером с холст (не больше 2048 по длинной стороне).

## Ввод
- Перо: давление, палец игнорируется, пока перо касается и 1.2 с после (ладонь не рисует).
- Палец: штрих начинается сразу; второй палец отменяет штрих (слой возвращается к состоянию до него) и превращается в жест камеры (щипок, сдвиг).
- Наклон пера (`AXIS_TILT`) пока не используется: Compose его не отдаёт, шейдеру этапа 1 он не нужен.

## Этап 2: пресеты, зерно, превью, меню
- **Пресет** (`BrushPreset`, `BrushPresets`): название и `BrushParams` (размер, шаг, форма, жёсткость, Flow, режим, зерно). Шесть кистей (Перо, Маркер, Аэрограф, Карандаш, Скринтон, Квадратный маркер) и три ластика (жёсткий, мягкий, квадратный). В C++ те же поля приходят как `Renderer::BrushPreset` (shape, hardness, grainKind, grainMode, grainScale, grainContrast) на `paintBegin`.
- **Зерно** (`GrainMath`): процедурные бесшовные текстуры 256x256 (карандаш - периодический value-noise с порогом, скринтон - решётка точек под 45 градусов с периодом 32 px, бумага). Передаются в GL как R8 с `GL_REPEAT`, кэшируются на контекст.
- **Canvas Space UV**: `grainUV = worldPos / (grainTextureSize * grainScale)`, где worldPos - пиксель слоя (vWorld из вершинного шейдера). Режим MOVING - UV штампа. Из-за этого повторный мазок попадает в те же точки скринтона, текстура не «мылится» при тонкой линии.
- **Квадрат**: бинарная отсечка `step(max(abs(q.x), abs(q.y)), radius)`, без smoothstep.
- **Превью**: `Renderer::brushPreview` рисует S-образный мазок (`BrushPresets.previewDabs`, давление 0.05 -> 1 -> 0.05) тем же движком штампов в Offscreen FBO 256x64 и читает RGBA через `glReadPixels`; в Kotlin превью превращается в `ImageBitmap` и кэшируется по id пресета. Ластик в превью рисуется чёрным.
- **Меню**: кнопка пресета в панели (превью + название) открывает выезжающую панель-Popup со списком; тап выбирает пресет (цвет остаётся текущим).
